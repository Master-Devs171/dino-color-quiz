# Segurança do DinoPlay

Não publique vulnerabilidades que possam expor crianças, responsáveis, amizades ou sessões multiplayer num issue público. Contacte primeiro o mantenedor através do separador **Security > Report a vulnerability** do GitHub.

Inclua apenas passos técnicos mínimos, versão afetada e impacto. Nunca inclua dados pessoais, códigos de amizade ativos, identificadores completos, fotografias ou conversas de crianças.

Problemas comuns sem dados sensíveis podem usar o formulário “Problema num jogo”. Um jogo com risco confirmado pode ser removido imediatamente do catálogo enquanto é investigado.
