DinoPlay · Informação para responsáveis

Política de privacidade

Última atualização: 21 de outubro de 2026. A DinoPlay é uma plataforma de jogos infantis concebida para funcionar sem publicidade, chat, localização, câmara, microfone ou contactos.

Dados guardados apenas no dispositivo

  • jogos instalados, progresso, recordes e personalizações;
  • idioma e preferências da aplicação;
  • PIN parental e código de recuperação, protegidos por hash;
  • credenciais técnicas aleatórias do multiplayer.

Estes dados não são enviados para fins publicitários e não são vendidos.

Multiplayer opcional

O multiplayer vem bloqueado. Se um responsável o ativar, o serviço processa um identificador aleatório do dispositivo, um segredo técnico de autenticação, o apelido escolhido pelo responsável, amizades aprovadas e presença temporária. Não são pedidos nome completo, email, telefone, data de nascimento, escola ou morada.

As partidas usam ligação WebRTC entre amigos autorizados. Para estabelecer essa ligação, os fornecedores de rede podem processar endereços IP e informação técnica de ligação. A DinoPlay não usa estes dados para localização, publicidade ou criação de perfis.

Finalidades e conservação

Os dados multiplayer servem apenas para autenticar o dispositivo, mostrar amigos autorizados, indicar presença e estabelecer partidas. Convites e sessões expiram rapidamente. O perfil e as amizades permanecem até um responsável os apagar na Área dos Pais ou remover cada amizade.

Prestadores

O site é disponibilizado através do GitHub Pages. O serviço multiplayer e a sinalização são processados pela Cloudflare. Estes prestadores podem tratar dados técnicos de rede necessários à segurança e entrega do serviço segundo as respetivas políticas.

Jogos da comunidade

Os jogos comunitários são revistos antes da publicação e executados numa área isolada. Não podem usar publicidade, rastreadores, ligações externas, autenticação própria nem recolher dados pessoais. O acesso a armazenamento e multiplayer depende das permissões aprovadas pela plataforma.

Controlo e eliminação

Área dos Pais → Privacidade
Um responsável pode apagar o perfil multiplayer, o apelido, as amizades e a identificação do dispositivo guardados no serviço. Limpar os dados da aplicação no Android apaga o progresso e as definições locais.

Segurança e contacto

Vulnerabilidades ou questões de privacidade podem ser comunicadas de forma privada através de GitHub Security Advisories. Não inclua nomes, fotografias, códigos ativos ou outros dados de crianças.

Esta página deve corresponder sempre às respostas da secção “Segurança dos dados” da Google Play. Alterações à recolha, multiplayer, prestadores ou monetização exigem atualização desta política.
